# CeyTech Labs

CeyTech Labs is a modern technology-services website built to present software development, IoT, digital solutions, and creative technology services through a clean, responsive interface.

The project focuses on building a polished business-facing frontend with clear service presentation, smooth interactions, and a direct contact workflow.

## Highlights

- Responsive modern landing page
- Services and company overview sections
- Portfolio / previous-work presentation
- Animated UI interactions with Framer Motion
- Contact form integration with EmailJS
- Reusable React components
- Mobile-friendly navigation and layout

## Tech Stack

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- EmailJS
- ESLint

## Getting Started

```bash

cd CeyTechLabs
npm install
npm run dev
```
